```
emacs --batch --debug-init -Q -l 某个文件.el
  │       │        │          │      │
  │       │        │          │      └─ -l = --load:加载后面这个文件
  │       │        │          └─ -Q = 完全干净启动:不加载任何你自己的配置
  │       │        │                 (没有 init.el、没有自动加载、没有启动画面)
  │       │        └─ --debug-init = 一旦加载出错,把"错误现场"(文件、行号、调用链)完整打出来
  │       └─ --batch = 批处理模式:不开窗口、不等人操作,跑完就退出,结果直接打印在终端
  └─ emacs = 程序本身
```

合起来的含义:「开一个全新空白的 Emacs(完全不理我的真实配置),只加载这一个文件,如果它有任何问题,把错误从哪一行哪个函数引起的完整打出来。

关键点在于 -Q 和 -l 的组合:
- 有 -Q → 你的真实配置被隔离在一边 → 出问题一定是这个文件自己的问题,不是和别的配置打架
- 有 -l → 只测这一个文件 → 错误信息非常干净,不会被别的加载噪音干扰
